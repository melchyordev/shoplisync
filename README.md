# ShopliSync

### Info

- App based on the project built in this [YouTube video tutorial](https://www.youtube.com/watch?v=HqOiB2tDM8Q) from Code With Beto
- [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app)
- Clerk for auth
- Tinybase for real-time syncing, offline support, and persistence
- Cloudflare Durable Objects for server and db storage
